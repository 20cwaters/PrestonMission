DROP HIS PHOTOS HERE
====================

Each week, put this week's photos in this folder and the automation will rename
them, file them into ../ (the photos folder), and move the originals into _filed.

Any of these work:
  - The .zip from Gmail's "Download all attachments" button (it gets unzipped for you)
  - Individual .jpg / .png files downloaded one at a time
  - Anything dragged in from anywhere

Filenames do not matter. The automation matches each picture to its caption by
looking at what is actually in the photo.

If you would rather use Google Drive, save them into a Drive folder named
"Preston Mission Photos" instead and leave this folder empty.
